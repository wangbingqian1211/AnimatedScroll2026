# 古画剧情视频：提示词审核流程

本次更新将视频从「完整原画原地微动」调整为「画风与人物延续的独立剧情分镜」。旧的代码核查报告与诊断JSON保留为更新前快照。

## 生成规则

- 每场独立5秒，无需与相邻视频保持机位、站位或首尾构图连续。
- 画风及人物外貌、发式、衣冠与服饰特征作为最高优先级延续，优先使用画中已有角色；人物在参考画中的坐标用于辨认外貌，不固定生成后的站位。
- 按剧情安排动作、人物位置、构图、环境视角，可使用中景、近景、特写、切镜及运镜。
- 防止同一角色既留在背景原图又出现一个会动的分身。未定位角色默认以画外声音出现，需要新增可见人物时先补充设定再审核。
- 使用 reference_image 模式：原画提供画风参考，出场人物裁切各自提供外貌参考；不再固定首尾帧。画面中未出场的角色不会自动全部加入参考。实际人物与画风保持程度仍需通过输出核对。

## 使用步骤

进入「剧本与分镜 → 古画动画」：

1. 点击「整理并查看最终提示词」：保存当前分镜，再从服务器读取实际编译文本，免费，不提交视频任务。
2. 在「实际发送给视频模型的 prompt」中修改。
3. 点击「保存最终提示词」：仅保存草稿，不算审核通过，不提交视频。
4. 勾选「我已审核上方已保存的最终提示词」，再点击生成。

提交时直接使用保存的完整字符串，不再拼接隐藏的前后缀。分镜、剧本、人物、参考画或生成设置变化后，旧提示词会过期，需重新整理/保存/审核；只修改最终文本也会撤销旧的生成确认。

已存在的镜头和对白不会被自动重写。旧稿如含「固定全幅、位置不变」等要求，会在审核区域提示用户；可直接删改最终提示词，或先修改镜头分镜再重新整理。

## 字段与请求

初稿会使用场景补充描述、每镜时长、景别、运镜、出场人物、动作、对白、旁白、音效。具体时间轴及对白以逐镜安排为准。最终手工修改文本独立保存于项目的 `sceneVideoPrompts` 中，避免与分镜摘要混淆。

现有模型与参数保持：`wan3.0-video`、480P、5秒、音频开启、seed=20261026、prompt_extend=false。界面会展示这些设置及「原画与人物裁切仅作参考，不绑定首尾帧」的输入方式。

请求指纹包含最终文本、模型、参数、输入方式及提示词策略版本；任务还绑定场景和图片哈希。相同请求去重，参数变化也会使旧审核失效。已排队旧任务按各自保存的配置处理，不把旧任务悄悄改成新请求。

接口：

- `GET /api/projects/{pid}/scenes/{sid}/video-prompt`：取得编译稿、已保存稿及过期状态，不使用视频额度。
- `POST /api/projects/{pid}/scenes/{sid}/video-prompt`：使用版本号与输入指纹保存最终文本，不使用视频额度。
- 原有确认与生成接口现在均校验已保存的最终提示词及审核状态。`test=true` 也不能绕过审核。
