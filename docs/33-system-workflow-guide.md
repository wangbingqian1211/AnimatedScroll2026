# AnimatedScroll 工作逻辑与使用顺序

本说明根据当前代码与页面整理。界面调整只改变呈现和展开方式，保存、生成、确认、人物关联和视频额度规则沿用现有实现。

## 先记住一条主线

**选画 → 整理资料与基础人物 → 写剧本 → 整理线索 → 完善人物档案 → 准备分镜 → 入画体验。**

也可以分成三个阶段来理解：

1. **准备依据**：这是什么画？画里有谁？哪些信息有原文支持？
2. **创作故事**：发生什么？人物知道什么、怎样说话？每一幕怎样呈现？
3. **体验作品**：观众选择人物交谈，发现线索，观看对应的分镜。

## 每一步负责什么

| 页面 | 输入 | 主要工作 | 产出供哪里使用 |
| --- | --- | --- | --- |
| 作品首页 | 已有项目或新画作 | 打开项目；新建项目；按需导入示例、归档与恢复 | 进入创作工作区 |
| 资料与基础人物 | 古画、文献、文本、图片 | 整理作品信息、人物、关系、事件与原文依据；标出人物位置，关联身份或补充称谓 | 为剧本、线索和人物档案提供基础 |
| 剧本大纲 | 资料、基础人物、创作方向 | 写剧情目标、发展、出场人物与画面区域；准备剧情关联的叙事线索 | 为线索、人物知识和分镜提供故事结构 |
| 线索库 | 资料与剧情 | 按文化背景、人物关系、叙事等类型组织可探索的信息，关联人物与依据 | 决定对话可透露的内容及相关分镜 |
| 人物档案 | 基础人物、剧情和线索 | 完善小传、关系、可知线索、自称、性格、说话方式与引导问题 | 为入画对话提供角色设定 |
| 分镜管理 | 线索、人物和画面区域 | 准备取景、参考人物、动作、运镜、起止画面与提示词；检查和逐镜审核 | 为体验中的视觉呈现提供分镜内容 |
| 欣赏作品 | 当前已可用的制作内容 | 开始或恢复体验；点击人物对话；记录线索并观看相关分镜 | 保留体验进度与对话记录 |

这些步骤有推荐顺序，也允许返回修改。页面上的必要缺项提示来自原有检查规则；换页本身不会自动完成前置制作。

## 最容易混淆的三个“人物”

### 画中身影：这个人在哪里

画上的一个人物框，包含位置、可见衣饰、动作和身份对应。一个框不等于一份独立人物档案。

### 资料人物：资料里提到了谁

来自文献或手动补充的角色。资料可能提到作者、收藏者或其他背景人物，这些人不一定出现在画里。

### 人物档案：这个角色如何参与故事

在基础人物上继续补充小传、关系、知识与对话设定。画中框通过角色 ID 关联这份档案；群体角色可以共用档案，同时保留多个身影的位置。

因此，资料页的姓名对应和人物档案页并非重复建人：前者解决“这个框是谁”，后者解决“这个角色知道什么、怎样说话”。

直接命名会创建或关联角色，并记录为创作者命名；不会凭空补成有史料依据的身份和经历。同名角色仍按原规则提示关联已有角色。

## 剧本、线索和分镜的区别

- **剧本**组织故事：这一段发生什么、为什么发生、谁在场。
- **线索**组织可发现的信息：观众能从谁那里了解到什么，它有什么依据。
- **分镜**组织画面：用哪个画面区域、哪些人物、什么动作与运镜表现一段内容。

它们会互相关联，但不是同一段文字在三个页面重复填写。

## 保存、生成、确认分别意味着什么

| 操作 | 当前行为 |
| --- | --- |
| 自动保存 | 保存输入和草稿，不调用模型。网络失败时保留待保存输入。 |
| 当前步骤的生成 | 明确点击后为当前步骤排队生成，不代表自动跑完整条流程。模型功能需要有效配置。 |
| 人工确认 | 记录你核对过的内容及其相关依据，不自动把创作或推测提升为已验证史实。 |
| 待复核／待更新 | 提醒相关内容或依据变化；与缺少必要内容的阻塞不同，按页面具体提示处理。 |
| 智能修改 | 先选择范围，再输入要求，只处理该范围及必要关联，可撤销。 |
| 制作检查 | 汇总必要缺项、任务问题和复核提醒，提供定位入口。 |
| 保存副本 | 手动下载创作备份，和日常自动保存用途不同。 |

可用的 AI 内容可以继续参与制作，人工复核通常是补充核对；真正缺少必要输入时，仍由原有规则限制相应操作。并行修改不同字段可合并，同一字段的真实冲突仍要求选择。

## 目前视频的实际边界

当前视频模型待接入。可以准备、修改、检查和保存分镜，但不能据此认为已经生成视频。体验可以使用已有内容和原画叙事等呈现方式，界面会区分实际视频与图像呈现。

额度是应用内使用上限，不是供应商账单；这次 UI 调整没有接入模型或修改额度。

## 建议第一次先这样走

1. 打开一幅画，浏览人物框，补上必要的姓名对应。
2. 添加与画作相关的主要文献，整理摘要和人物依据。
3. 到剧本页，只聚焦一条清楚的故事主线。
4. 到线索库，检查故事所需线索与人物的关联。
5. 到人物档案，完善关键人物的知识与说话方式。
6. 准备关键分镜，再去欣赏作品中验证对话和线索是否连贯。

过程中只处理当前步骤所需的内容。高级检测、OCR、旧版资料、实验统计和归档恢复在有需要时再展开。

## 本轮界面整理

- 首页优先展示真实项目的画作卡片，流程图与项目管理按需展开。
- 资料页优先展示画作，下方保留可搜索的人物缩略图。
- 点击画中框或缩略图，右侧仅展示当前人物详情；未选择时显示操作引导。
- 上传、更换图片、补框、删除和撤销等操作集中在画作工具中。
- 文献与作品资料作为独立区块保留，避免与人物浏览挤在同一列。「整理资料／更新资料」位于文献资料区域，生成摘要、人物候选、原文依据与作品资料库；基础人物供姓名对应及人物档案共用，不触发后续步骤的新内容生成。
- 智能修改面板可展开、收起，避免覆盖画作与人物列表。

更完整的操作规则见 [简化审核与工作流](22-review-workflow.md)、[资料整理](30-material-pipeline.md) 和 [分镜视频](31-video-production.md)。
