# 从旧数据库选择已有资料

入口：**资料与基础人物 → 文献与作品资料 → 资料来源 → 选择已有史料**。

折槛图项目默认显示已有资料选项。没有加入文献时，资料来源区域默认展开。其他画作可在「全部资料」中查看，但不要把折槛图的专门材料误用于其他画作。

## 已接入的内容

从原项目 `D:\2026study\1230WU\AnimatedScroll2026` 使用的 MySQL 中只读提取折槛图资料，去除重复的制作摘要，保留四份独立整理笔记：

1. 画作档案与解释边界。
2. 朱云传 · 用户整理的事件笔记。
3. 主要人物 · 用户整理笔记。
4. 张禹传 · 背景与时间边界。

这批资料主要是用户既有整理文字，并非独立上传的 PDF 或原书全文。主文本沿用旧示例项目中保存的版本；两份笔记在旧项目中存在人物称谓差异，其他版本保存在同一条目的「查看旧库其他版本」中。出处和原始项目、来源编号随资料保留，不静默修改旧库文字，不自动标记已核验。

「互动创作意图」没有作为史料提供；与上述笔记重叠的三段制作摘要也没有重复列出。

## 使用方式

1. 勾选要使用的资料，可以先展开全文、出处及版本差异。
2. 点击「加入所选资料」；资料加入当前项目的文献列表，可直接预览文字。
3. 按需点击本区「整理资料」，沿用已有模型整理流程。

浏览和加入已有资料都不调用模型，不创建新角色、剧情或分镜，也不替代人工确认。重复加入自动跳过；通过文本编辑修改导入内容后，保留来源标识，不用原库版本覆盖用户编辑。

## 存储和更新边界

资料快照位于 `examples/source-library/zhekan.json`。正常使用无需保持旧 MySQL 运行，也不需要在当前应用配置旧库密码。本次没有修改旧 MySQL 的表或项目。

这是可随项目携带的离线资料快照，旧库日后发生的变化不会自动同步。加入当前项目后，文字、出处及来源信息随该项目的正常保存、备份和文献整理流程使用。

接口：

- `GET /api/projects/{pid}/source-library`：列出条目、推荐范围及已加入状态。
- `POST /api/projects/{pid}/source-library/import`：携带当前版本和所选条目 ID，原子加入资料，重复项复用。

导入在保存冲突或失败时清理本次新增的文字文件，不清理已有资料。
